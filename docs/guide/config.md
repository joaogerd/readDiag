# Configuration & Environment

- `READDIAG_LOG_FILE=1` habilita logging em arquivo (padrão: console apenas).
- `READDIAG_LOG_PATH=/caminho/arquivo.log` define o caminho do log.
- `READDIAG_DATA` / `READDIAG_DATA_TEST` apontam diretórios de dados.
- `use_memmap=True` reduz RAM em radiância (trade‑off: I/O mais alto).
